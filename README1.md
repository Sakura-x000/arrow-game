# 一箭又一箭

## 项目名称
一箭又一箭（Arrow Out）

## 游戏简介
点击棋盘上的箭头，让它朝自己的方向飞出棋盘。
如果前方有别的箭头阻挡，则不能飞出，并消耗一次失误。
清空全部箭头即通关，失误耗尽则失败。

## 开发环境
- Python 3.10+
- Pygame 2.5+

## 安装和运行方法
1. 安装 Python
2. 命令行执行：`pip install pygame`
3. 进入项目目录，执行：`python main.py`

## 游戏操作说明
- 鼠标点击箭头：尝试飞出
- 点击“重新开始”：重置本关
- 通关后按 N：进入下一关
- 失败或通关后按 R：重开本关
